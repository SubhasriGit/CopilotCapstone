# Documentation Skills

| Skill | Definition |
|---|---|
| README Generation | Writes the project README and setup guidance |
| API Documentation | Documents endpoints and request/response formats |
| Architecture Docs | Summarizes the system architecture clearly |
| Runbook Creation | Documents deployment, rollback, and incident steps |
| Developer Onboarding | Explains how to build and test the project |
| Safety Documentation | Documents hooks, secrets handling, and self-healing behavior |
