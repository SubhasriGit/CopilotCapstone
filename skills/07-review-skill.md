# Review Skills

| Skill | Definition |
|---|---|
| Code Review | Checks correctness, style, and maintainability |
| Security Review | Searches for secrets and insecure patterns |
| Design Compliance | Compares implementation to approved design docs |
| Hook Verification | Confirms pre-commit hooks are present and functional |
| Self-Healing Verification | Checks resilience logic on external calls |
| Report Writing | Produces PASS/WARN/FAIL findings clearly |
