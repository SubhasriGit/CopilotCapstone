# Design Skills

| Skill | Definition |
|---|---|
| Architecture Design | Defines layered system structure and boundaries |
| Component Design | Specifies responsibilities and interfaces per component |
| Data Modelling | Designs domain entities, schemas, and relationships |
| API Contract Design | Defines request/response shapes and error handling |
| Security Design | Specifies secret handling, validation, and TLS usage |
| Hook Design | Designs secret scanning and connection validation hooks |
