# Testing Skills

| Skill | Definition |
|---|---|
| Unit Test Design | Creates tests for individual classes and methods |
| Integration Test Design | Verifies component interaction and application wiring |
| Security Testing | Validates secret and injection protections |
| E2E Test Design | Covers user-facing flows end to end |
| Hook Testing | Confirms hook behavior on violations |
| Fault Injection | Simulates failures to verify self-healing |
