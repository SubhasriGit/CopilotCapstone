# Deployment Skills

| Skill | Definition |
|---|---|
| Build & Package | Produces the deployable application artifact |
| Environment Configuration | Uses environment variables for runtime config |
| CI/CD Pipeline Setup | Configures automated build/test/deploy steps |
| Deployment Execution | Runs the release to the target environment |
| Post-Deploy Validation | Checks health and smoke tests after release |
| Rollback Management | Restores the last known good version on failure |
