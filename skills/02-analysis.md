# Analysis Skills

| Skill | Definition |
|---|---|
| Requirement Intake | Reads the Confluence source and requirement file |
| Stakeholder Analysis | Identifies who is affected by the project and why |
| Feasibility Review | Assesses technical, operational, and timeline feasibility |
| Scope Definition | Defines in-scope and out-of-scope items |
| Risk Analysis | Records risks with practical mitigations |
| Open Question Tracking | Captures unresolved blockers for later phases |
